# Конспект марафона «Вся химия с нуля до ЕГЭ за 12 часов»

Полный текстовый конспект открытого 12-часового стрима школы **Профиматика**
(преподаватель — Владислав Кварц): https://www.youtube.com/live/s4d9DKnlCpE

## Как читать

Откройте **`konspekt/index.html`** — это одностраничный сайт:

- слева — оглавление по главам с автоподсветкой текущей;
- у каждого заголовка — плашка `▶ Ч:ММ:СС` со ссылкой на нужный момент видео;
- картинки кликабельны (открываются в полном размере);
- кнопка **«Скачать PDF»** — печать всей страницы в файл.

Файл самодостаточен: картинки встроены как base64, интернет для чтения не нужен.

## Состав

| Путь | Что это |
|---|---|
| `konspekt/konspekt.md` | исходный markdown конспекта (63 главы, 0:02:20 → 11:54:00) |
| `konspekt/index.html` | собранный HTML-конспект (главный файл для чтения) |
| `konspekt/img/` | иллюстрации (схемы связей, решётки, таблица Менделеева, ряды активности, электролиз) |
| `tools/build.py` | сборка: markdown → HTML, таймкоды → ссылки, картинки → base64 |

## Пересборка

```bash
python3 tools/build.py
```

Требуются `markdown` и `Pillow`:

```bash
pip3 install --user --break-system-packages markdown pillow
```
